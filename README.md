# 飞岩走壁（微信小程序）

## 功能概览
- 首页：岩馆搜索与列表、进入打卡
- 打卡：抱石/难度切换、等级加减、提交打卡
- 统计：最近 30 天折线图、最近记录
- 我的：同步微信头像昵称、馆长后台、名片相关入口
- 馆长模式：我的岩馆、岩馆管理（信息/周期/线路录入）
- 名片：创建、赠送、领取、保存、上墙

## 云开发对接
- 小程序端使用 `wx.cloud.DYNAMIC_CURRENT_ENV` 初始化云环境
- 云函数与集合名按云开发控制台截图一致（RockGyms、RockUsers 等）

## Summary

将名片制作页从“多块卡片+大量字段同时出现”的编辑形态，改为“单页预览 + 必填最少 + 更多设置折叠”的结构，降低信息密度与操作成本，同时保持现有保存规则（保存即写云端并消耗 1 次 credit）。

## Current State Analysis

- 制作页位于 [card-edit](file:///c:/Users/jeo/Documents/trae_projects/feiyanzoubi/miniprogram/pages/card-edit/index.wxml)，当前分为三张大卡片：正面、反面、一句话；字段全部同时可见，视觉与交互负担较高。
- 云端保存函数 [rock_card_upsert](file:///c:/Users/jeo/Documents/trae_projects/feiyanzoubi/cloudfunctions/rock_card_upsert/index.js) 强制要求 `back.story` 非空，并且每次保存都会消耗 credit（用户已确认保持现状）。
- 当前已具备头衔/MBTI 底部弹窗选择器（sheet），可沿用。

## Decisions (confirmed)

- **保存规则**：保持现状（点保存即写云端并消耗 1 次 credit）。
- **默认项**：默认微信名+头像、头衔随机默认、常去岩馆默认“浪迹天涯”。
- **结构**：单页 + “更多设置”折叠。

## Proposed Changes

### 1) 重新布局 card-edit：单页预览 + 最少必填 + 更多设置

目标：进入页面后用户只需做两件事也能完成保存：写故事（必填）+（可选）选照片；其它字段默认填好且隐藏在“更多设置”。

改动文件：
- [card-edit/index.wxml](file:///c:/Users/jeo/Documents/trae_projects/feiyanzoubi/miniprogram/pages/card-edit/index.wxml)
- [card-edit/index.wxss](file:///c:/Users/jeo/Documents/trae_projects/feiyanzoubi/miniprogram/pages/card-edit/index.wxss)
- [card-edit/index.js](file:///c:/Users/jeo/Documents/trae_projects/feiyanzoubi/miniprogram/pages/card-edit/index.js)

具体方案：
- 顶部增加“名片预览”区域（非 canvas，纯 WXML）：展示头像、名字、头衔、MBTI、浪迹天涯/常去岩馆摘要、一句话（若已生成/填写）。
- 主编辑区只保留：
  - 背面故事 textarea（必填，作为第一视觉重点）
  - 选择照片按钮（可选）
  - 生成一句按钮（当 story 非空时可用，默认风格使用当前 oneLinerStyle；风格切换放到更多设置）
  - 保存按钮（保持现有行为与文案）
- “更多设置”折叠区（默认收起）包含：
  - 名字输入（默认填微信昵称；可改）
  - 头像：用微信 / 自定义上传
  - 头衔：点击打开现有 sheet 选择器（包含“随机一个”）
  - MBTI：点击打开现有 sheet 选择器
  - 常去岩馆：默认勾选“浪迹天涯”；关闭后才出现输入框（最多 3 家）
  - 一句话：手动编辑 textarea（可选）；风格 tabs（鼓励/幽默）
- 交互细节：
  - 点击预览区域可切换“正面预览/反面预览”（反面显示照片状态 + 故事摘要），减少用户上下滚动确认内容的成本。
  - 生成一句失败/未写故事时提示保持不变。

### 2) 默认值策略（仅首次创建生效）

改动文件：
- [card-edit/index.js](file:///c:/Users/jeo/Documents/trae_projects/feiyanzoubi/miniprogram/pages/card-edit/index.js)

策略：
- 若为新建（无 cardId）：
  - displayName：优先取 `getApp().globalData.user.nickName`，否则留空，保存时仍会兜底为“岩友”。
  - avatar：默认 `avatarMode='wechat'`；如全局 user 有 avatarUrl，则写入 `front.avatarUrl`（不上传文件）。
  - title：自动随机一个（直接写入 front.title）。
  - wanderer：默认 true（并清空 gymsText/front.gyms）。
  - oneLinerStyle：默认 humor（保留可在更多设置切换）。
- 若为编辑已有 cardId：完全以云端数据回填为准，不覆盖用户已有选择。

### 3) 样式与代码精简

目标：在保证紫/黄撞色与简洁美观的前提下，减少重复样式与无用结构。

改动文件：

措施：

- 保留现有 sheet 选择器样式，不再引入新的复杂组件。
